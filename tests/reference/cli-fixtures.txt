# CLI end-to-end reference stems for `scripts/gen-cli-reference.sh` (Plan 8 Task 6).
#
#   stem|dsn|extra_args|lane
#
# `dsn` is relative to the Java checkout ($FREEROUTING_JAVA_DIR, default ../freerouting).
# `extra_args` is everything the argv carries after `-de <dsn> -do <out>`, space separated, or `-`
# for a bare run. `lane` is `ci` (runs under a plain `cargo test`) or `slow`
# (`#[cfg_attr(debug_assertions, ignore)]` + `FR_SLOW_PARITY=1`), which is Plan 7's split carried
# over unchanged.
#
# The generator writes, into tests/reference/cli-<stem>/:
#
#   argv.txt      the argv, one token per line, with `<JAVA_DIR>` and `<OUT>` placeholders
#   route.ses     the **bare HEAD jar**'s SES, verbatim
#   route.exit    its exit code
#   route.log     its stdout followed by its stderr, machine-specific prefixes replaced
#   manifest.json the manifest a second run with `--router.result_json=<f>` wrote
#   meta.txt      the jar identity, `java -version`, the hash mode, the budget note, the argv and
#                 the `batch.ses` cross-check verdict
#
# ## Scan ruling R1 — the `-mp` cap is transcribed, not invented
#
# The first eight rows are Plan 7's batch stems with **the same argv `batch.meta.txt`'s `bare jar`
# line records**, cap included. A bare `-de/-do` would run `router-dac2020-bm01` at unlimited
# passes, which quirk #234 proves unmeasurable (`-mp 3` scores 841.0115, `-mp 20` scores
# 835.88336, and the same `-mp 20` under DEBUG logging scores 841.0115 again). Keeping Plan 7's
# argv also buys a free cross-check the generator asserts: `cli-<stem>/route.ses` must be
# byte-identical to `<stem>/batch.ses`, which `gen-batch-reference.sh --verify-driver` already
# proved is the bare jar's output. Two independently generated references agreeing is worth more
# than either alone.
#
# ## The two round-trip stems
#
# `tutorial_board` and `Issue026-J2_reference` are the Plan 3/5 DSN/SES round-trip boards, run
# **bare** — no `-mp`, no enable flags — because nothing else in the table exercises the plain
# user command line and `DefaultSettings.java:99`'s `maxPasses = 9999` with it. Measured: the bare
# `Issue026-J2_reference` run answers the same 15 254 bytes as the `-mp 99` row, in 4.4 s.
