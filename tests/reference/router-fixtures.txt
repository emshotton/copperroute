# Router reference fixtures for scripts/gen-router-reference.sh (Plan 6 Task 17).
#
#   stem|dsn|max_items|ripup_pass_no[|max_passes|fanout|optimizer]
#
# Fields 1-4 are `scripts/gen-router-reference.sh`'s (Plan 6 Task 17); fields 5-7 are
# `scripts/gen-batch-reference.sh`'s (Plan 7 Task 16). Each script reads only its own columns and
# skips a row that carries `-` in the first of them, so the two reference families share one
# table without either being able to describe the other's run.
#
# `dsn` is relative to the Java checkout ($FREEROUTING_JAVA_DIR, default ../freerouting).
# `max_items` is the number of connections `P6T1` routes: it walks `board.getItems()` (descending
# item id, quirk #63) × each item's own net index order and keeps the `(item, net)` pairs whose
# `getUnconnectedSet` is non-empty, stopping at `max_items`. A number larger than the board's
# candidate count therefore means "every connection of the board"; that is deliberate for the two
# stems where it is affordable, because ruling 1's acceptance is per connection and a truncated
# board hides the congested connections — which are the only ones that rip.
#
# `max_items` and `ripup_pass_no` are **mandatory or `-`** on every row (Plan 7 Task 16 made them
# so; `-` in `max_items` means "not a per-connection row" and `-` in `ripup_pass_no` means the
# default 1). `max_passes|fanout|optimizer` are the batch columns: `settings.maxPasses` (`-mp`),
# and `on`/`off` for `--router.fanout.enabled` / `--router.optimizer.enabled`. A row with no
# `max_passes` is a per-connection-only row and `gen-batch-reference.sh` skips it.
#
# `ripup_pass_no` is `AutorouteConnectionRouter.route:45`'s multiplier — `ctrl.ripupCosts =
# startRipupCosts * ripupPassNo`, i.e. which pass of `AutoroutePassRunner`'s loop the connection is
# being routed in. It defaults to **1**, the value every stem below the last one uses; the last one
# pins **2**, where the multiplier and `MazeRipupResolver`'s ripup pricing are live. Plan 6 Task 17b
# added it: pass 1 matched by compensation over a search tree whose *shape* had already diverged
# (quirk #74), and only a pass >= 1 exercise reaches the connection that shows it.
#
# The stems are prefixed `router-` so they cannot collide with the DSN/SES reference stems in
# fixtures.txt or the DRC stems in drc-fixtures.txt.
