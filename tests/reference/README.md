# Java reference outputs

Generated by `scripts/gen-reference.sh` from the pinned freerouting 2.3.0 jar
(the parity baseline per the Java repo's AGENTS.md). For each stem in
`fixtures.txt` the script produces:

- `<stem>/roundtrip.dsn` — Java `DsnReader.readBoard` → `DsnWriter.write`, no routing
- `<stem>/unrouted.ses`  — same board → `SesWriter.write`, no routing (0 `(wire` entries)
- `<stem>/java.log`      — driver output, for debugging

## How it works (and why not `-de/-do`)

The script compiles `scripts/gen-reference/RefWriter.java` against the jar and
runs it per fixture. The normal `-de/-do` job path was tried first and cannot
produce these references:

- `-do <file>.dsn` is accepted but the headless job writer only emits SES or
  KiCad JSON, so the DSN output is an empty file.
- `-mp 0` means *unlimited* passes, not zero.
- `--router.enabled=false` disables only the autoroute stage; fanout and the
  optimizer still run and modify the board (fanout added vias/wires).
- With all three of `--router.enabled=false --router.fanout.enabled=false
  --router.optimizer.enabled=false` the job completes with nothing to do and
  writes 0 bytes.

Note the 2.3.0 jar's package layout predates the clone's renames
(`app.freerouting.board.BasicBoard`, not `board.facade`); the driver imports
the jar's names.

Reference files are committed. `_scratch/` holds the Rust side of a failing
comparison and is gitignored, as is `scripts/gen-reference/build/`.

Requirements: JDK 25 (`brew install openjdk@25`, then
`JAVA=/opt/homebrew/opt/openjdk@25/bin/java scripts/gen-reference.sh`), network
access on first run to download the jar into `tools/`.
