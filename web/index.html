      Run it on your own machine

      $ git clone https://github.com/emshotton/copperroute.git
$ cd copperroute
$ cargo build --release
# route a board and write a session file; an adjacent .kicad_pro is found automatically
$ ./target/release/copperroute route board.kicad_pcb -o board.ses

# or route a Specctra DSN the same way
$ ./target/release/copperroute route board.dsn -o board.ses

# or serve the routing tools over MCP (JSON-RPC on stdin/stdout)
$ ./target/release/copperroute mcp
# register that server with Claude Code
$ claude mcp add copperroute -- ./target/release/copperroute mcp

      Needs a Rust toolchain; the pinned version is in rust-toolchain.toml. Run copperroute --help for the full command list.

      What this handles

      Standard pads, straight tracks, through vias and one closed Edge.Cuts outline. Rounded pads keep their corner radius for hole clearance, and routing uses the enclosing rectangle. Internal cutouts become fixed obstacles on every copper layer. Convex custom pads with a covered circular anchor and offset drill holes are supported. Keepouts that restrict tracks or vias and other custom pad shapes are rejected.

      Supply a .kicad_pro alongside a KiCad board to apply its project net classes and supported DRC constraints; manual rules apply otherwise. Custom .kicad_dru files are not supported. DSN files already carry their own rules, net classes and layer settings, and their preview shows routing geometry without source-editor artwork. Download the SES session to bring routing back into the source editor.

      Zone definitions survive routing but cached fills do not. Press B in KiCad to refill. Vias in SMD pads stay off unless you enable them and your fabricator supports the process. Optimization is disabled. Inspect the result and run KiCad DRC before manufacturing.
