Prototype support

DSN uses the native Rust importer and embedded rules, net classes and layer settings. Download the SES session to import routing into the source PCB editor. DSN preview shows routing geometry; source-editor artwork is not included.

Supports standard pads, straight tracks, through vias, and a single closed Edge.Cuts outline. Rounded pads retain their corner radius for hole DRC; routing uses enclosing rectangles. Keepouts that restrict tracks or vias, cutouts, custom pads and offset holes are rejected. Existing tracks (including arcs) and vias are removed, even when locked.

Uses imported project net classes and supported DRC constraints when a project is supplied; otherwise uses the rules above. Custom .kicad_dru files are not supported. Inspect the result and run KiCad DRC before manufacturing. Optimization is disabled for this prototype.
